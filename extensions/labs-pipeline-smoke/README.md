# Labs Pipeline Smoke Test

> Does nothing. Verifies the Indrasol Labs release pipeline.

**Do not install this extension.** It exists only to prove that the Indrasol Labs release pipeline
can package one VSIX and publish it to Open VSX and the VS Code Marketplace. It will be unpublished
from both registries once that is verified, and its name is never reused.

## What it contains

A copy of the Indrasol Labs extension template: a **Labs Smoke: Hello** command, the
"More from Indrasol Labs" view and a getting-started walkthrough.

## Privacy and telemetry

This extension makes no network calls and collects no telemetry. The events listed in
[`telemetry.json`](telemetry.json) are not collected.
