# Build notes

One `<extension>.md` per launched extension: how it was built, the design decisions, and the
task prompts Claude Code implemented, in order. See [`../how-we-build.md`](../how-we-build.md)
for the overall process.

Each page follows this outline:
1. What the extension does and why we built it
2. Key design decisions (with links to ADRs)
3. Task prompts, in order, each with a one-line outcome
4. What we learned
